This is a project on Music Recommendations Engine using Flask api, where there is a registration and login facility that is followed by a user entering a song name out of the 114,000 songs excel (.csv file) dataset and 5 songs are recommended in return based upon the genre of the entered song.
This project has been made using node js for the backend as well as Flask api. 
For the frontend, I have used React js along with tailwind and postcss for the the User Interface. 
For the database, MongoDB has been used and even AWS S3 with a bucket and a Identity and Access Management (IAM).
